# I16: Evaluate frozen models on the shared real test set

## Background

A defensible result requires consistent predictions and clearly defined metrics.

## Objective

Deliver: Metric definitions, results tables and uncertainty limits.

## Scope

Compute required macro/per-class metrics, confusion matrices and paired comparisons from sealed test predictions.

## Out of scope

Any retraining or hyperparameter adjustment based on test. No work in this issue is implemented by the planning foundation.

## Implementation guidance

evaluation module; schema-checked probabilities, fixed label order, zero_division=0 and count reconciliation. Follow the architecture contracts and experiment protocol; do not silently change interfaces.

## Dependencies

#15. Work may start only after prerequisite artifacts are reviewed.

## Deliverables

- Metric definitions, results tables and uncertainty limits.
- Focused source/configuration/documentation changes and reproducible verification evidence.
- Versioned artifact metadata where the stage produces research outputs.

## Acceptance criteria

- [ ] Every arm predicts exactly the same test IDs once per checkpoint
- [ ] Confusion counts sum to test support
- [ ] Accuracy/macro precision/recall/F1 and per-class results exported
- [ ] Across-seed SD only reported when repeated runs exist

## Testing requirements

Hand-computed confusion fixture, absent class, invalid probabilities and duplicate/missing ID rejection.

## Documentation requirements

Update the relevant module usage, contracts and metric definitions, results tables and uncertainty limits. Link evidence and disclose unexecuted checks. Keep README status accurate.
