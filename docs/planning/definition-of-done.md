# Definition of Done

- Assigned issue scope and dependencies understood; all acceptance items have evidence.
- Focused implementation respects module contracts and approved protocol.
- Relevant unit/integration/failure checks run; CPU CI passes; real GPU validation is identified separately.
- Dataset/model/config/seed provenance recorded where applicable; no leakage or invented results.
- Docs and executable examples updated; limitations and unexecuted checks explicit.
- No secrets, raw datasets, model weights or generated datasets in the diff.
- One peer approves and required checks pass before merge; actual issue closes only after deliverables exist.
- AI contributors provide the nine-item AGENTS.md completion report.

Planning a feature does not satisfy implementation acceptance. A failed experiment may be a valid research finding when documented, but must not be presented as a successful implementation/run.
